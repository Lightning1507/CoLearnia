# Tiếp tục UI CoLearnia

**Bàn giao ngày 05/11/2026: UI chưa hoàn thiện toàn diện.** Đã có các màn và hành trình chính; còn nhánh nghiệp vụ thiếu, ca chưa kiểm và bước review cuối của team. Đây là prototype Figma, chưa phải frontend/backend đã triển khai.

Đọc theo thứ tự:

1. [Handoff](figma-handoff.md): phần **Đọc nhanh**, mục 2–3 và **5.1 — R1–R6** để biết cách tiếp tục.
2. [Current-state](figma-current-state.md), **mục 19**: đã làm gì, độ phủ 57 FR đang áp dụng, phát hiện từ đọc mã, ca chưa kiểm và điều kiện khép UI. Mục 8–18 giữ bằng chứng lịch sử để tra theo ca.
3. Nguồn nghiệp vụ được dẫn ở các mục trên; [brief](figma-make-brief.md) chỉ dùng tra phong cách/prompt cũ.

Tiếp tục [file Figma Make hiện tại](https://www.figma.com/make/4ATlhcdwYqUYUlcRgB9jCn/D%E1%BB%B1ng-Workspace-v%C3%A0-Chat-CoLearnia). Card mới nhất là v14, nhưng code hiện tại có sửa C/D/E sau v14; **không khôi phục v14 hoặc dựng lại app từ đầu**. Public chưa được cập nhật bởi các lượt này. Prompt từng hết credit; kiểm quyền/công cụ thực tế, code editor vẫn sửa được ở lần kiểm gần nhất.

Lượt kế tiếp là **R1: kiểm chat riêng giữa người ở nhóm và host MAIN; kiểm vào LIVE khác khi đang có call**. Tái hiện trước, sửa trong phạm vi đã giao, tự kiểm preview rồi cập nhật current-state. Không tự chọn nghiệp vụ còn mâu thuẫn. Đưa việc được giao/trạng thái lên GitHub Issues theo workflow; các tài liệu này chỉ giữ hiện trạng thiết kế, cách kiểm và bàn giao.

Prompt tiếp nhận có sẵn trong handoff mục 6. Chưa có ủy quyền publish, commit hoặc push cho lượt tiếp nhận chỉ từ việc đọc các tài liệu này.
