# CoLearnia — quy chuẩn thiết kế và phát triển

Thư mục chung cho các bộ quy chuẩn theo frontend/backend. Nghiệp vụ và quyết định kỹ thuật hiện hành vẫn theo [mục lục tài liệu](../README.md) và [trạng thái quyết định](../decision-status.md); không tạo bản sao nguồn API hoặc workflow ở mỗi bộ.

## Frontend

- Khi nhận task FE: [hướng dẫn thực hiện](frontend/fe-task-guide.md).
- Khi làm với Codex: [quy trình và ví dụ giao task cho AI](frontend/codex-task-workflow.md).
- Khi tổ chức code: [kiến trúc frontend](frontend/code-architecture.md).
- Trước gửi review: [checklist tác giả/reviewer](frontend/review-checklist.md).
- Khi chuyển code Figma: [lộ trình áp dụng](frontend/figma-adoption.md).
